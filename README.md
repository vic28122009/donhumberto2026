# 🏗️ Don Humberto - Materiales para la Construcción

Sistema web de gestión integral y catálogo digital para corralón de materiales.

## 🚀 Funcionalidades principales
* **Control de acceso por roles:** Redirección automática según credenciales (Administrador, Empleado o Cliente).
* **Panel Administrador:** Resumen de métricas, control de inventario/precios, registro de pedidos, nómina de personal, logística y reportes.
* **Panel Empleado:** Gestión de pedidos en mostrador, seguimiento de estados y consulta de stock.
* **Portal Cliente:** Catálogo visual con buscador en tiempo real, filtros por rubro y consulta de disponibilidad.

## 🔑 Credenciales de prueba
* **Administrador:** Usuario `admin` / Contraseña `123` (también habilitados `jlopez`, `mlopez`, `cgomez`).
* **Empleado:** Usuario `EMP001` / Contraseña `emp123` (también habilitados `juanperez`, `marialopez`).
* **Cliente:** Ingresar cualquier otro nombre de usuario y contraseña.

## 🛠️ Tecnologías utilizadas
* HTML5
* Tailwind CSS
* JavaScript (Vanilla)
* FontAwesome
